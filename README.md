# MCToolKit

A fast, browser-based tool for creating and converting Minecraft modpacks.
If you want to add a feature fee free to add it!
Instead of manually searching and adding every mod, simply paste your mod list, choose your target platform, and export a ready-to-use modpack.

## Features

* Supports **CurseForge** and **Modrinth**
* Convert mod lists into complete modpacks
* Cross-platform conversion
* Runs entirely in your browser
* No installation required
* Free to use

## How it works

1. Select your target platform.
2. Paste your mod list.
3. Review the detected mods.
4. Download your generated modpack.

## Why MCToolKit?

Creating or converting modpacks manually can be time-consuming. MCToolKit simplifies the process by automating mod detection and package generation, allowing you to create working modpacks within seconds.
